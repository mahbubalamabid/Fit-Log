# FitLog

FitLog is a workout library application where users can explore workouts, view workout details, create a daily workout plan and save workouts for later.

## Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI
- react-hot-toast

## Features

- Browse a workout library with search and sorting.
- View detailed information and instructions for each workout.
- Add workouts to Today's Plan, with a maximum of 5 workouts.
- Save workouts for later.
- Mark planned workouts as completed or pending.
- Persist the workout plan and saved workouts using localStorage.
- Responsive design for desktop, tablet and mobile.
